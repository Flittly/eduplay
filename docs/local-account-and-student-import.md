# 本地教师账号与学生积分规则

## 本地账号

- 本地账号使用用户名 + 密码登录。
- 密码使用 BCrypt 加密后保存在本地 H2 数据库中。
- 登录成功后生成一个本地 Token，有效期为 30 天。
- 前端将 Token 保存在 localStorage 中，退出登录前一直有效。
- 退出登录后本地账号数据仍然保留，重新登录即可恢复积分。

当前平台使用者是教师账号，学生只是教师名下的名单数据，不提供学生登录。

## 学生导入 Excel 规则

模板列：

| 列名 | 是否必填 | 说明 |
|---|---:|---|
| 姓名 | 必填 | 学生姓名 |
| 学号 | 必填 | 唯一，且不能与已有账号重复 |
| 班级 | 可选 | 最大 64 字符 |
| 初始积分 | 可选 | 0 到 99999 |

导入规则：

- Excel 文件必须包含“姓名”和“学号”两列。
- 姓名不能为空。
- 学号不能为空，不能重复。
- 学号不能与平台已有账号重复。
- 初始积分不合法时，整行校验失败。
- 所有行校验通过后才会批量导入。
- 任一数据校验失败，本次文件不会导入任何学生。

学生名单默认规则：

- 学生不创建登录账号
- 学生归属于导入该名单的教师
- 学生包含姓名、学号、班级和总积分
- 初始积分 = Excel 中填写的值，未填写则为 0

## 学生维护

- 前端把「学生积分」和「学生名单维护」分开：学生积分页用于搜索、查看积分、调整积分和导出；学生管理页用于导入、添加和删除学生。
- 学生积分页支持导出 xlsx，导出文件的列与导入模板一致（姓名 / 学号 / 班级 / 初始积分），最后一列填写学生当前积分，可用于名单备份或在另一台设备上恢复导入。
- 已经导入过学生后，不需要重复导入。
- 教师可以单独添加学生。
- 教师可以删除学生。
- 教师可以手动增加或扣减学生积分。
- 每次积分变动都会记录流水。

## 云端账号

本地账号数据保存在本地 H2。

云端账号将在接入线上 MySQL 后实现：

- 本地账号可先在本机使用。
- 需要上传或同步云端时，再登录云端账号。
- 云端账号对应 MySQL 中的用户和积分数据。
